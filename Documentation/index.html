SafeVoice Buyer Documentation

v1.0.0 Spring Boot 3.4 React Native Expo 56 Next.js 16

Thank you for purchasing SafeVoice! This official documentation walks you through building, configuring, and deploying the backend service, cross-platform mobile application, admin moderation panel, and marketing landing page.

📋 Prerequisites

Ensure your environment has the following software installed before proceeding:

  • Java Development Kit (JDK 21+) — Required for backend.
  • Node.js (v20+ LTS) & npm — Required for mobile and frontends.
  • Docker & Docker Compose — Recommended for instant containerized deployment.
  • PostgreSQL 15+ & Redis 7+ — Required if running outside Docker.

📁 Monorepo Overview

Directory Technology Description
safevoice-backend/ Spring Boot 3.4 / Java 21 REST API, STOMP WebSockets, JWT Auth & Security
safevoice-app/ React Native / Expo 56 Cross-platform mobile application for iOS & Android
safevoice-admin/ Next.js 16 (App Router) Admin Moderation Portal & Audit Log Dashboard
safevoice-landing/ Next.js 16 / Tailwind v4 Marketing landing page and web promotional site

⚡ Quick Docker One-Command Setup (Recommended)

💡 Easiest Way to Deploy
You can launch PostgreSQL 15, Redis 7, and the Spring Boot backend with a single command! 
# 1. Copy the example environment template
cp .env.example .env

# 2. Start all services in detached mode
docker compose up -d --build

# Verify all containers are healthy
docker compose ps

🛠️ 1. Backend Manual Setup (`safevoice-backend`)

If you prefer running the backend manually via Maven:

cd safevoice-backend

# 1. Copy environment variables file
cp .env.example .env

# 2. Build the project
./mvnw clean package -DskipTests

# 3. Run the application
java -jar target/safevoice-0.0.1-SNAPSHOT.jar

📱 2. Mobile App Setup (`safevoice-app`)

cd safevoice-app

# 1. Install dependencies
npm install

# 2. Copy environment config
cp .env.example .env

# Edit .env and set your server's backend URL:
# EXPO_PUBLIC_API_URL=http://YOUR_SERVER_IP:8080/api/v1
# EXPO_PUBLIC_WS_URL=ws://YOUR_SERVER_IP:8080/ws

# 3. Start Expo local development server
npx expo start

Building Standalone APK / AAB for Play Store & App Store

# Build Android APK for testing
npx eas build -p android --profile preview

# Build Android AAB for Google Play Store
npx eas build -p android --profile production

🛡️ 3. Admin Moderation Portal Setup (`safevoice-admin`)

cd safevoice-admin

# 1. Install node dependencies
npm install

# 2. Copy environment file
cp .env.example .env.local

# 3. Run development server
npm run dev

# 4. Build for production (Netlify / Vercel / Docker)
npm run build

🌐 4. Landing Page Setup (`safevoice-landing`)

cd safevoice-landing
npm install
npm run dev

❓ FAQ & Support

How do I change the app logo and branding?
Replace the image assets located in safevoice-app/assets/images/ (icon.png, splash.png) and update the app name in safevoice-app/app.json.
