SafeVoice — Architecture Overview

An anonymous civic-engagement platform split into four services: a React Native mobile app, two Next.js web apps, and a Spring Boot API — deployed as a Docker backend on a DigitalOcean droplet behind Nginx, with the frontends shipped separately to Netlify's CDN. Explore the system

This diagram mirrors SafeVoice's real deployment topology. Client apps talk to Nginx over HTTPS and WSS; Nginx terminates TLS and forwards to the Spring Boot API on port 8080; the API reads and writes PostgreSQL, caches through Redis, and calls out to Firebase, Cloudinary and Brevo. A separate GitHub Actions pipeline builds and ships every service on merge to main.
